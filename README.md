## 1. Problem Statement

A traditional Ring doorbell alerts you that someone is there with an audible chime and a phone push notification with a tiny thumbnail. This interface fails for three key demographics:

1. **The Deaf or Hard-of-Hearing Resident:** Auditory chimes are inaudible. A phone vibration in another room goes unnoticed while watching television. A tiny thumbnail is insufficient to make an informed decision to open the door. (In the US alone, ~1 in 8 people aged 12+ has bilateral hearing loss — *NIDCD*).
2. **The Older Adult Living Alone:** The rush from an armchair to the front door is a major physical fall hazard. Unexpected visitors are also the primary vector for predatory doorstep scams.
3. **The Remote Family Caregiver:** Family members living miles away only find out about doorstep activity by manually scrolling through video clips after the fact, and they never learn what *didn't* happen (e.g., zero movement all morning, or a missed regular nurse visit).

---

## 2. What Porchlight Does

Porchlight converts any Ring doorbell into an ambient living room accessibility terminal:

- **10-Foot Television Visual Chime:** Replaces audible chimes with a full-screen Fire TV overlay (Vega OS) featuring **72px large typography** and a **24px animated flashing border** (2 Hz pulse for attention, 1 Hz for calm, silent by default).
- **Multimodal AI Intent Explanation:** Uses Amazon Bedrock vision models (`amazon.nova-lite-v1:0` or Anthropic Claude) to answer one question: *"Who is here and what do they want?"* in a plain-language sentence of at most 20 words (e.g., *"A courier in a high-visibility vest is holding a parcel at the door."*).
- **Privacy-First Schedule Matching:** Matches visitor roles and arrival times against an expected visitor schedule ("Nurse Priya, Tue/Thu 10:00") without biometrics. Expected visitors produce a calm green card; unexpected visitors trigger an attention alert.
- **Real-Time Live Captions:** When live view is opened, streams audio from the Ring WHEP WebRTC connection through **Amazon Transcribe Streaming WebSocket**, rendering instant speech-to-text captions on the video stream so Deaf residents can read what the visitor is saying.
  - *Honest note:* live Transcribe captions require an AWS paid plan. This deployment runs on the free plan, so the demo shows clearly labelled **"Demo captions"** (scripted phrases, not real speech); the dashboard switches to them automatically with a visible reason when Transcribe is unavailable, and with `?demo=clip`. The Transcribe presign Lambda and the event-stream client are implemented and would work on a paid plan.
- **Caretaker Daily Digest & Anomaly Engine:** Aggregates the day's events into a timeline with deterministic anomaly detection (`quiet_day`, `night_activity`, `unexpected_repeat`), paired with a warm <= 120-word summary generated by Amazon Bedrock for family members.

## 4. Hackathon Challenge Alignment

### 4.1 Ring Accessibility & Caretaking Grand Prize
- **100% Simulator Ready:** Tested and driven by the Ring Developer Portal Simulator without physical hardware or paid Ring subscriptions.
- **Visual Chime Replacement:** Solves hearing loss limitations by replacing audio with high-contrast living room television visuals and real-time live captions.
- **DevRel Feedback:** Delivers a complete [`docs/FRICTION_LOG.md`](docs/FRICTION_LOG.md) and [`docs/FEATURE_REQUESTS.md`](docs/FEATURE_REQUESTS.md) advocating for two-way audio APIs.

### 4.2 AWS Builder Mini-Challenge (9 AWS Services)
1. **Amazon Bedrock:** Multimodal vision inference via Converse API and text narration.
2. **Amazon Transcribe:** Real-time streaming speech-to-text live captions over WebSocket.
3. **Amazon DynamoDB:** Single-table architecture with conditional write deduplication and native TTL.
4. **Amazon SQS:** Buffering queue with dead-letter queue (DLQ) protecting webhook latency SLA.
5. **AWS Lambda:** 5 single-responsibility Python 3.12 functions on ARM64 Graviton architecture.
6. **Amazon API Gateway:** HTTP API v2 providing public webhook ingestion and client REST routes.
7. **Amazon S3:** Private frame storage with 7-day automated lifecycle expiration.
8. **Amazon EventBridge Scheduler:** Nightly cron trigger for automated caretaker digests.
9. **AWS Systems Manager (SSM):** Parameter Store `SecureString` credential management.
*(See full integration details in [`docs/AWS_INTEGRATION.md`](docs/AWS_INTEGRATION.md))*

### 4.3 Open Source Mini-Challenge (`ring-webhook-verify`)
- Extracted and published [`ring-webhook-verify`](ring-webhook-verify/) to PyPI and npm.
- Provides lightweight, zero-dependency HMAC-SHA256 signature verification and idempotency helpers in Python and TypeScript for Ring Partner API webhooks.

## 5. Quick Start & Development

### 5.1 Prerequisites
- Python 3.12+
- Node.js 20+
- AWS SAM CLI
- AWS Account configured with credentials

### 5.2 Running the Test Suite
Porchlight enforces strict, evidence-backed test verification:
```bash
# Activate virtual environment
source .venv/bin/activate

# Run all backend unit & integration tests (46 tests with moto AWS mocks)
pytest backend/tests/ -v

# Run open-source package tests
pytest ring-webhook-verify/python/tests/ -v
```

### 5.3 Simulating Webhook Events Locally
Use the included replay tool to sign and post test events:
```bash
python tools/replay/replay.py \
  --fixture fixtures/webhooks/button_press_courier.json \
  --target http://localhost:3000/ring/webhook \
  --hmac-key test-secret-hmac-key
```

### 5.4 Deploying Backend with AWS SAM
```bash
cd backend
sam build
sam deploy --guided
```

### 5.5 Running the Web Dashboard
```bash
cd dashboard
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view active cards, live stream video, and settings.

### 5.6 Running the Fire TV Card Application (Vega OS)
```bash
cd tv
cp src/config.example.ts src/config.ts   # then set the deployed API URL and passphrase
npm install
npm run build:app
```
Install on your Vega Virtual Device (VVD) using the Amazon Devices Builder Tools CLI.

## 7. Privacy & Responsible AI

Porchlight strictly enforces:
- **Zero Facial Recognition:** Never computes face embeddings or identifies individuals by face.
- **Zero Demographic Inference:** Strictly forbids guessing age, gender, or race.
- **7-Day Frame Expiration:** Doorstep images in S3 are purged after 7 days; presigned URLs expire in 1 hour.
